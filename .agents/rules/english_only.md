# Rule: English Only for Repository Files

All files that are part of the repository or pushed to GitHub MUST be written in English.

**Requirements:**
- All code, comments, and docstrings must be in English.
- All markdown documentation (including issue plans, READMEs, and `.agents` rules) must be in English.
- All commit messages and PR descriptions must be in English.

**Note:** You may continue to communicate with the user in the language they prefer (e.g., Spanish) in the chat interface, but the artifacts and files produced must strictly be in English.
